## 模板信息

| 属性 | 内容 |
|---|---|
| 系列 | Career 系列 |
| 风格 | 简约、经典 |
| 适用场景 | 实习 |
| 示例岗位 | 品牌市场实习生 |
| 示例模块 | 求职意向、教育背景、课程项目、校园经历、工具与能力 |

## 怎么用

- **在线使用**：在 [DrawOffer 职绘](https://www.drawoffer.com/templates) 的模板库里选择「蓝线传播履历」，可以直接编辑、导入已有简历，导出 A4 或智能一页 PDF。
- **拿示例数据**：[`template.json`](./template.json) 里是这份预览用的完整示例简历，结构见 [canonical-resume schema](../../schema/canonical-resume.schema.json)。

示例中的姓名、联系方式、公司和经历均为虚构，仅用于展示版式。
